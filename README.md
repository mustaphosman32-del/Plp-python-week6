# SpendWise - Interactive Budget Tracker## Project OverviewSpendWise is a budgeting application built with HTML, CSS, and JavaScript. It helps users manage their money by setting a budget, recording expenses, and monitoring their remaining balance.## Improvements Made This WeekThis week, I improved SpendWise by adding interactive JavaScript features. Users can:- Set and update their total budget.- Add multiple expenses with names, amounts, and categories.- View all expense records in a table.- Delete expenses.- Filter expenses by category.- View total expenses and their remaining balance.- See a progress bar showing the percentage of their budget used.- Receive warnings when their spending reaches 80% of the budget or exceeds it.## JavaScript Concepts Implemented### 1. Conditional StatementsI used `if`, `else if`, and `else` statements to make decisions.The application checks whether the remaining balance is negative. If it is, the dashboard displays an overspending warning.If the user has spent at least 80% of the budget, the dashboard displays a caution message. Otherwise, it shows a positive budget message.Conditional statements also validate budget and expense inputs.### 2. ArraysI used an array called `expenses` to store multiple expense records.Each record is an object containing:- An ID- An expense name- An amount- A category- A dateThe `push()` method adds new expenses, while the `filter()` method removes a selected expense from the records.### 3. LoopsI used `for` loops to process the expense array.The first loop calculates the total amount spent. Another loop displays the expense records in the dashboard.Loops make it possible to process multiple expenses without writing separate code for every record.### 4. DOM ManipulationI used JavaScript DOM methods to update the webpage dynamically.Examples include:- `getElementById()` to select HTML elements.- `textContent` to update budget figures and messages.- `createElement()` to create table rows and cells.- `appendChild()` to display records.- `style.width` to update the progress bar.These methods allow the dashboard to change without manually editing the HTML.### 5. Event ListenersI used event listeners to respond to user actions.- The budget form's `submit` event updates the budget.- The expense form's `submit` event adds a new expense.- The expense table's `click` event handles deletion.- The category filter's `change` event filters the records.The `preventDefault()` method prevents form submission from reloading the page.### 6. Connecting the ApplicationWhen a user adds or deletes an expense, JavaScript updates the array and recalculates the totals. The dashboard then displays the updated information.This connects user interactions, data processing, and DOM manipulation.## Challenges Encountered and Solutions### Challenge 1: Calculating the Total Expenses**Solution:** I created a function that uses a loop to add the amounts of all expense records.### Challenge 2: Updating the Dashboard**Solution:** I used DOM manipulation to update the totals, balance, budget percentage, feedback message, and expense table.### Challenge 3: Validating User Input**Solution:** I used conditional statements to reject empty expense names and invalid or non-positive amounts.### Challenge 4: Managing Expense Records**Solution:** I stored expenses in an array and used array methods to add and remove records.## TestingI tested the application by checking the following:- Setting and updating the budget.- Adding expenses with different categories.- Checking whether totals and balances update correctly.- Filtering expenses by category.- Deleting expenses and checking the recalculated totals.- Checking the warning when 80% of the budget is used.- Checking the warning when expenses exceed the budget.- Entering invalid amounts to verify input validation.## Technologies Used- HTML5- CSS3- JavaScript## How to Run the Project1. Download or clone the repository.2. Open the project folder in Visual Studio Code.3. Open `index.html` in a web browser.4. Set a budget and start adding expenses.## AuthorSalah Omar
